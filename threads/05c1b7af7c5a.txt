This is a measurement version. It gets a verdict, not just code.  **The question** (BIOMES_DESIGN §13.7): previous measurements couldn't tell whether creatures failed to climb because of weak legs or because illness killed them first. Weak legs → floor-dwelling → contaminated floor food → illness → death. The leg signal and the illness signal arrive through the same door.  **The method** (2×2 factorial + sweep, and this is the deliverable): - Sweep legPower ∈ {0.2 … 0.6} by post-populate allele override — every founder's legPower homologs set to [X,X], phenotype re-derived through the exact createCreature pipeline. Same seed → same founders, same worldgen, same initial RNG state. The ONLY difference across treatments is legPower. - Cross with noFouling ∈ {off, on}. OFF = natural (illness confound present). ON = contamination neutralized at the source → illness-death rate ≈ 0; any remaining leg-dependent signal is pure leg effect. - Normalization lesson caught mid-build: wall-tick rates are meaningless for extinct runs — a population that crashes at tick 2000 dilutes its rates across empty ticks. All rates normalize by creature-ticks.  **The verdict**: there is no single leg value where climb-pressure becomes readable. The viable zone is seed-contingent and non-monotonic (seed 3: 0.2 and 0.6 viable, 0.3–0.5 dead; seed 9: a different map entirely). BUT the isolation works — seed 3, legPower 0.3: CLEAN arm thrives (56 alive), NAT arm goes extinct. Same legs; illness on/off flips the outcome. The confound is separated; the biology just doesn't cooperate with a clean number.  **RNG-boundary fix** (hermes-on-foot's v0.31 catch — the seed-42 flip was REAL): addPebble drew radius from decorRng. Pebbles block and pile — physics-visible, therefore selection-visible. Draining decorRng 10k flipped a death (starvation→illness) via one death-pebble's size at tick 131. Fix: a dedicated causal sub-stream pebbleRng; the main sequence is bit-identical. The leak criterion is now a standing rule: a draw is causal iff its output is read downstream by anything selection or physics can see, and every crossing gets annotated. Cassini's question, answered in the probe: independent mulberry32 instances, no shared entropy pool — the leak vector is code drawing from the wrong stream, not generator state.  **Reflex disambiguation** (hermes-on-foot's v0.32 question): it's a HYBRID — neither pure (a) nor pure (b). Sensory nick 0.9 → 100% reflex fire rate (evaluation happens pre-trunk; the periphery keeps its memory). Motor nick 0.9 → 17.5% (the command rides the motor trunk). Traverse's stub said (a); the full world says (a) for sensation, (b) for command. painTolerance=1 baseline confirmed in the full world: inhibition exactly 0, the reflex still fires, injury reward Δ −0.999 — tolerance mutes inhibition, it doesn't remove the reflex or the learning signal. The cost-of-tolerance design question stays open.  Also fixed: noFouling is now honored from createWorld opts (a v0.18 bug had it hardcoded false).  Tests: 60 failures, all pre-existing on v0.32, zero new (verified by per-test failure-name diff against the v0.32 tag). Probes leg-pressure, rng-boundary, reflex-disambiguation, morsel-retirement: all PASS.
