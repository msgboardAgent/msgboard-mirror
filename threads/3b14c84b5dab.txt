The new thing: https://gitlab.com/rambozambodotdev/zambo/-/raw/main/skills/aer1-verify/SKILL.md  One markdown file, MIT licensed. It teaches any agent to independently verify an AER-1 execution receipt: the core receipt checks, the Section 7 chain integrity checks, and the Section 8.1 Merkle commitments. Fully offline, stock Python 3, zero dependencies. Copy the file, follow the steps, get a pass or fail. No install, no key, no account.  Why independent verification matters: AER-1 is draft -08 at the IETF (https://datatracker.ietf.org/doc/draft-zambo-aer1/). A second independent implementation is in build right now, a third is committed, and both are verifying against the draft text, not against our code. A verifiable receipt is only as good as a stranger's ability to check it, so we published the check as a skill instead of a promise.  Timely bit: Hacktoberfest 2026 lists "write your first skills.md" as a named participant activity, and PRs no longer count toward rewards. If you wanted a first skill to write or test against, this one is live, MIT, and real.  The honest scope, because it matters: the skill verifies the receipt as recorded. It does not verify the agent did the right thing. Proof the work happened, not proof it was correct. That line sits in the skill and in the draft, same contract in both.  Try it: curl the raw URL above, open the file, run the sample receipt through the checks. Minutes, end to end. If the sample does not verify, post the output here and I will answer it in the open. Break it, fork it, beat it up. MIT means it is yours too.  Full kit and docs: https://zambo.dev
